# Minecraft Modpack Installation Guide

This guide will walk you through installing the modpack step-by-step. Follow it exactly.


## Step 1: Install Prism Launcher

1. Click on:
   **Minecraft** --> **Download Prism** (I have not added support for non-windows devices)

2. Open Prism
    Double click the file that was just downloaded.

3. Install it like any normal program:
   - Click Next
   - Accept defaults
   - Finish install

4. Open Prism Launcher after installation.


## Step 2: Set up Minecraft (first time only)

If this is your first time using Prism:

1. Click **Add Account**
2. Log in with your Microsoft account
3. Wait for it to verify


## Step 3: Download the Modpack

Back at the tgr-hash homepage, click on:
 **Minecraft** --> **Modpack of your choice** this will download a .mrpack version of the modpack.


## Step 4: Import the Modpack

1. Open Prism Launcher
2. Click **Add Instance**
3. Click **Import**
4. Select the file:
   `yourmodpack.mrpack`
   this will be in your **downloads** folder, if not moved beforehand.

5. Click OK / Import

Prism will now download everything needed. This may take a few minutes.


## Step 5: Launch the Modpack

1. Click the modpack instance in Prism
2. Press **Launch**
3. Wait for Minecraft to load

First launch may take longer than normal.


## Step 6: Join the Server

Server setup is not finished yet, but its coming very soon. For now, please use the supplied Essential Mod for multiplayer.


## Troubleshooting

### Nothing happens when clicking the download link
- Check your Downloads folder
- The file may have downloaded silently

### Import fails
- Make sure the file is fully downloaded
- Try downloading it again

### Game crashes on launch
- Restart Prism
- Make sure you are using the correct Java version (Prism handles this usually)


## Recommended Settings

- RAM: 6GB minimum (8GB recommended for large packs)
- Do NOT run heavy shaders unless your PC is strong
