# Minecraft Modpack Installation Guide

This guide will walk you through installing the modpack step-by-step. Follow it **exactly.**


## Step 1: Install Portable Modpack

1. Click on:
   **Minecraft** --> **All of Create Modpack (Installation method 2)** 

2. Open Folder
    Double click the file that was just downloaded. This will problably be in your downloads folder.

3. Unzip Folder
   - Right Click **Portable_modpack.zip**
   - Click **Extract All** (usually on the top of the file explorer window)
   - This should open the unziped folder in a new window 


## Step 2: Run and Set up

Inside the newly unzipped Portable_modpack folder:

1. Double click **PLAY.bat**
2. If a window pops up saying **Windows protected your pc**, click **Learn More** then **Run anyway**
3. This should open up an app called Prism Launcher. Once you sign in with your microsoft acount, click on the modpack of your choice, then **Launch**. Thats it!


## Done

Thats it! Nothing else you need to do.
